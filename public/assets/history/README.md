# History icons

Project symbols (wop.svg, wordless-mage.svg, galactica.svg, triple-showdown.svg, lone-lantern.svg, defair.svg) are original SVG illustrations made for this portfolio. They use the projects' flower/planet, spell hand, ship/orbit, three cards, lantern and wrench motifs; they are not third-party institutional logos.

Institutional images:
- club-mark.webp: official I2P × O2CUBE mark, cropped only to remove surrounding whitespace. Source page: https://i2pxo2cube.pages.dev/ ; original: https://i2pxo2cube.pages.dev/images/2026Logo.png
- game-software-mark.webp: Hongik Game Software major's mark, cropped from its official page image. Source page: https://www.husg.net/game-software/ ; original: https://www.husg.net/wp-content/uploads/2021/05/logo_gsw-290x290.jpg
- game-academy.webp: mascot detail cropped from Netmarble's official Game Academy fourth-cohort recruitment poster. This is a poster-derived activity icon, not a claim of a separate official Academy CI. Source: https://ch.netmarble.com/Newsroom/Detail?bbs_code=1013&post_seq=957

Institution marks belong to their respective owners. CSS displays the icons in grayscale; original source colors are retained in the image files.
