# Tool icons

SVG assets are bundled locally so the profile does not depend on external image hosts.

- Unity, C++, Python, OpenAI (ChatGPT), Jira, Confluence: Simple Icons 13.0.0, https://github.com/simple-icons/simple-icons/tree/13.0.0/icons (CC0).
- PowerPoint, Excel, Word: Simple Icons 9.0.0, https://github.com/simple-icons/simple-icons/tree/9.0.0/icons (CC0).
- Claude, ElevenLabs: https://github.com/simple-icons/simple-icons/tree/develop/icons (CC0).
- C#: https://github.com/devicons/devicon/blob/master/icons/csharp/csharp-original.svg (MIT; see LICENSE.devicon.txt).

Simple Icons SVG fill colors are set for contrast against the site's dark background. Product names and logos belong to their respective owners.
